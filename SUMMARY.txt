                                THE BUG
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

BUGGY CODE (Current):
─────────────────────
    dd_pct = (entry_price - float(cur_exit)) / float(entry_price) * 100.0

PROBLEM:
────────
This formula ONLY works for UP positions. For DOWN positions, when price
increases (causing loss), the result is NEGATIVE, preventing stop-loss from
triggering.

EXAMPLE - DOWN Position Losing Money:
──────────────────────────────────────
    Entry: BUY DOWN @ 0.50
    Current Price: 0.60 (price went UP = you lose 20%)
    
    Buggy calculation:
    dd_pct = (0.50 - 0.60) / 0.50 * 100 = -20%
    
    Stop-loss check:
    if -20% >= 10%:  ← FALSE! Stop-loss DOES NOT trigger!
        trigger_stop_loss()

RESULT: You keep losing money without protection! 💸

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
                                THE FIX
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CORRECTED CODE (Only 3 lines to change!):
──────────────────────────────────────────
    if entry_side == 'UP':
        dd_pct = (entry_price - float(cur_exit)) / float(entry_price) * 100.0
    else:  # entry_side == 'DOWN'
        dd_pct = (float(cur_exit) - entry_price) / float(entry_price) * 100.0

EXAMPLE - Same DOWN Position with Fix:
───────────────────────────────────────────
    Entry: BUY DOWN @ 0.50
    Current Price: 0.60 (price went UP = you lose 20%)
    
    Fixed calculation:
    dd_pct = (0.60 - 0.50) / 0.50 * 100 = 20%
    
    Stop-loss check:
    if 20% >= 10%:  ← TRUE! Stop-loss TRIGGERS correctly! ✅
        trigger_stop_loss()

RESULT: Loss is limited to 10% as intended! 🛡️
